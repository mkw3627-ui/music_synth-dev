# 为她而唱（music_synth）

让 N.E.K.O 在你的电脑上，用你的声音唱歌。

「为她而唱」是 N.E.K.O 的本地翻唱与原创歌曲插件。你可以让她翻唱正在听的歌，也可以用文字让她从零写一首歌，再用你训练的音色唱出来。唱的时候角色会上台演出，每首歌都能单独选演出模式。

## 她能做什么

- **只听你选的应用**：只采集选中程序的声音，通知、视频和她自己的声音都不会混进来。
- **自动切歌**：根据静音和媒体标题的变化把歌分开，太短的片段会自动合并。
- **训练你的音色**：投入一段素材，自动完成分离、降噪、切片和特征提取，然后训练音色，每 2000 步会出一段试听。
- **翻唱变声**：使用 DDSP-SVC 6.3 把人声换成你的音色，伴奏保持不变，最后混回一首完整的歌。显存不够时会自动换用更轻的档位。
- **原创歌曲**：用 ACE-Step 从文字生成整首歌，可以指定歌词、风格、BPM、时长，也可以只要纯音乐。
- **一键成曲**：生成后自动分离、变声、混音，直接得到成品。
- **唱歌舞台**：逐字对口型，歌词排版，有两种演出模式（原舞台和手书分镜），画质会按你的电脑自动调整。
- **声音包导入导出**：把模型和配置打包成一个 zip，换电脑或分享给朋友都很方便。
- **全部在本地完成**：音频不会上传到任何地方。

## 安装

1. 在 N.E.K.O 的插件页安装「为她而唱」。
2. 打开面板，按新手引导第 4 步选择安装目录，然后点「一键安装」。引导页会列出要装的环境、程序和模型，每项的来源和大小都写得清楚，并且可以先「测下载速度」，看哪个下载源又快又通。默认走国内镜像。
3. **唱歌舞台（可选）**：舞台需要在 N.E.K.O 的宿主页面里加一个小加载器。关掉 N.E.K.O，然后在插件目录里运行：

   ```
   python -I host/apply_solo_stage.py            # 安装（会自动找 Steam 里的 N.E.K.O；找不到时用 --host 指定 resources\bin）
   python -I host/apply_solo_stage.py --check    # 检查是否已安装
   python -I host/apply_solo_stage.py --revert   # 还原（改之前会整个文件备份）
   ```

   N.E.K.O 自己更新后，可能需要重新运行一次安装。不装舞台不影响翻唱和原创歌曲，只是唱的时候没有舞台演出。

## 你的电脑能跑什么

插件会自动检测 CPU、显卡（NVIDIA、AMD、Intel）和内存，为每个功能选择合适的方案：

| 功能 | NVIDIA 显卡 | AMD / Intel 显卡或无独显 |
|---|---|---|
| 翻唱（分离 + 变声） | 显卡加速，满质量 | CPU 加速，可以用（45 秒的歌约需 6 分钟） |
| 歌词识别 | 显卡加速 | CPU 加速（int8） |
| 训练音色 | 需要 6GB 以上显存 | 不建议 |
| 原创歌曲（ACE-Step） | 需要 6GB 以上显存（XL 模型需要 12GB） | 暂不支持（这种情况下会随机崩溃） |
| 唱歌舞台 | 全部效果 | 自动降到均衡或轻量档 |

建议配置：Windows 10 或 11，NVIDIA 显卡 8GB 显存以上，16GB 以上内存。
