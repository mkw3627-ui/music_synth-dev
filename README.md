# 为她而唱（music_synth）

N.E.K.O 的本地 AI 翻唱与原创歌曲插件。

采集正在播放的音乐 → 自动切歌 → 人声/伴奏分离 → DDSP-SVC 6.3 音色转换 → 混回伴奏，
一条链路出成品；也能用 ACE-Step 从文字直接生成整首歌，再用训练好的音色重唱一遍。
唱的时候角色上台演出：「原舞台」（人物在场上，运镜 + 背景 + 歌词）或「手书分镜」（画面为主），每首歌可单独选。

## 能做什么

- **只听选中的应用**：逐进程声道采集，通知、视频、AI 自己的声音都不会混进来
- **自动切歌**：按静音能量谷和媒体标题变化切分，短片段自动合并
- **音色训练**：投素材 → 分离/降噪/切片/提特征 → 训练 DDSP-SVC 音色，每 2000 步出试听
- **双引擎变声**：DDSP-SVC 6.3（RectifiedFlow）；按显存自动选档位、自动降级
- **原创歌曲**：ACE-Step v1.5 本地 text2music，支持歌词、风格、BPM、时长、纯音乐；可选舞台模式
- **一键成曲**：生成后自动分离、变声、混音，直接出成品
- **唱歌舞台**：逐字口型、歌词排版、两种演出模式（原舞台 / 手书分镜），画质按电脑配置自动调
- **声音包导入导出**：模型 + 配置打包成 zip，换机或分享都方便
- **全本地**：音频不上传

## 安装

1. 在 N.E.K.O 插件页安装 `music_synth.neko-plugin`。
2. 打开「为她而唱」面板，按新手引导选安装目录、勾选想用的功能、一键安装基础环境。
   装完基础环境就能进主页，大模型在后台静默下载（页面底部常驻下载条可看进度）。
3. **唱歌舞台（可选）**：舞台要在宿主页面里加一个加载器。关掉 N.E.K.O 后运行：
   ```powershell
   python -I host/apply_solo_stage.py            # 安装（自动找 Steam 里的 N.E.K.O；找不到用 --host <resources\bin>）
   python -I host/apply_solo_stage.py --check    # 检查
   python -I host/apply_solo_stage.py --revert   # 还原（改前会整文件备份）
   ```
   N.E.K.O 自身更新后可能需要重新运行一次。不装也不影响翻唱和原创，只是唱的时候没有舞台演出。

### 下载分级（T0 / T1 / T2）

- **T0 基础环境**：便携 Python、虚拟环境、PyTorch、音频工具（ffmpeg）、pip 依赖。必须前台装完才能进主页。
- **T1 程序**：DDSP-SVC 仓库等小体积代码（< 50MB），和 T0 一起前台装。
- **T2 模型**：声音模型、去伴奏模型、ACE/SoulX 权重等大文件，进主页后**后台静默下载**。

下载全程**不随页面/插件中断**：切页、关面板、关 N.E.K.O 都会继续；断网/磁盘满会自动暂停，恢复后续传。
每个文件都做 sha256 校验，换源前比对末尾 64KB，慢源自动切换到更快的镜像。

### 各功能清单与体积

| 功能 | 前台（T0+T1） | 后台（T2 模型） | 需要 NVIDIA |
|---|---|---|---|
| 翻唱（默认勾选） | 便携 Python + venv + torch + DDSP 依赖 + audio-separator + ffmpeg | ContentVec、声码器、RMVPE、人声分离权重（约 2.3GB） | 否 |
| 音色训练 | 同翻唱 | + 训练底模（可选高/低质量底模） | 不建议（CPU 极慢） |
| 原创歌曲 | + ACE 依赖 | ACE 基础模型（约 6GB；其它 DiT 可选） | 是（≥6GB 显存） |
| SoulX 唱法 | 共用环境 | SoulX 权重（约 5.8GB） | 是 |
| 听歌采集（默认勾选） | 采集组件 | — | 否 |
| 唱歌舞台 | 随插件发布 | — | 否 |

体积以安装向导里的「测下载速度 / 部署清单」为准，会按所选功能与硬件实时计算。

### 离线使用与断点续传

- **安装完成后完全离线可用**：翻唱、训练、原创生成都在本机跑，音频不上传。
- **下载可断点续传**：`.part` 文件保留已下部分，重启后自动接着下，不用从头再来。
- **多镜像自动换源**：每个大文件备了多个源（ModelScope / 阿里云 / NJU / hf-mirror / GitHub 镜像），
  自动测速选最快、校验哈希；国内源速度通常快一个数量级。

### 常见问题

- **下载慢**：在「设置 → 下载速度与来源」点「测速」，看各源实速；把「下载源偏好」切成「国内源优先」。
  慢到阈值会自动换源，不用手动干预。
- **断网 / 中断**：任务会停在已下位置，网络恢复后自动续传；不会重头下。
- **磁盘空间不足**：任务自动暂停（`磁盘满·暂停`），清出空间后 30 秒内自动恢复。
- **校验失败**：文件损坏会自动从另一个源重下；仍失败会在下载条标红并给「重试」。

## 电脑配置

插件会自动检测 CPU、显卡（NVIDIA / AMD / Intel）和内存，按配置给每个功能定方案：

| 功能 | NVIDIA 显卡 | AMD / Intel 显卡、无独显 |
|---|---|---|
| 翻唱（分离 + 变声） | 显卡加速，满质量 | CPU 加速，可用（45 秒歌实测约 6 分钟） |
| 歌词识别 | 显卡加速 | CPU int8 加速 |
| 训练音色 | 需 ≥6GB 显存 | 不建议 |
| 原创歌曲（ACE-Step） | 需 ≥6GB 显存（XL 模型 ≥12GB） | 暂不支持（PyTorch 在 CPU 上会随机崩溃） |
| 唱歌舞台 | 全效果 | 自动降到均衡 / 轻量档 |

建议：Windows 10/11，NVIDIA 显卡 8GB 显存以上，内存 16GB 以上。
